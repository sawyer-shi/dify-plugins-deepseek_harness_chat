## English Version

### Overview

The DeepSeek Harness Chat plugin ("Plugin") connects the Dify platform to a **self-hosted** [dsh-openai-gateway](https://github.com/sawyer-shi/dsh-openai-gateway) running inside your own DeepSeek Harness (DSH) installation. Every API call is executed by a real DSH agent session with tools and a workspace on **your own machine**. This privacy policy explains how we handle your data when you use the plugin within the Dify platform.

This plugin is licensed under the MIT License, a permissive open-source license that allows use, modification, and distribution. The full license text is available in the LICENSE file included with this plugin.

### Data Collection

**What we DO NOT collect:**
- Personal identification information
- Usage analytics or tracking data
- Device information
- Location data
- Cookies or similar tracking technologies
- Any telemetry sent to the plugin author or any third party

**What we process:**
- Text prompts you send to the DSH agent
- Files you attach to a message (documents, spreadsheets, images…), which are uploaded to the agent workspace on your machine
- Files generated by the agent during a turn (Excel, CSV, PDF, …), which are downloaded from the agent workspace and returned to your Dify conversation
- The gateway API key (Bearer token) you configure as a credential

### Data Processing

**Local Processing (primary path):**
- All requests are sent to the gateway Base URL **you** configure — by default `http://127.0.0.1:41540` on your own machine, or a LAN address you own
- Prompts, attachments, and generated files stay on your machine and your Dify instance; they are never transmitted to the plugin author or any cloud service operated by us
- The DSH agent executes tasks locally (its workspace is a local directory)

**Upstream AI Services:**
- The DSH agent itself calls the DeepSeek model services it is logged in to; that traffic is handled by DeepSeek Harness under **DeepSeek's own privacy policy**, not by this plugin
- If you configure the gateway Base URL to point at a remote host, data flows to that host under your control — review its security accordingly

**Local Session State:**
- Sticky-session mappings (Dify conversation/user → gateway session id) are held in plugin process memory only and are lost on restart
- No permanent data storage beyond plugin runtime logs

### Security Measures

- The gateway authenticates with a Bearer API key stored securely in Dify's plugin credential storage
- If DSH and Dify run on the same machine, traffic never leaves localhost; for cross-host deployments, keep the gateway inside a trusted network
- The plugin makes no network connections other than to the Base URL you configure

## 中文版本

### 概述

DeepSeek Harness Chat 插件（"插件"）将 Dify 平台连接到你**自托管**的 [dsh-openai-gateway](https://github.com/sawyer-shi/dsh-openai-gateway)——它运行在你自己的 DeepSeek Harness（DSH）安装之中。每次 API 调用都由**你自己机器上**带工具与工作区的真实 DSH Agent 会话执行。本隐私政策说明你在 Dify 平台内使用本插件时，我们如何处理你的数据。

### 许可证信息

本插件采用 MIT 许可证，这是一个宽松的开源许可证，允许使用、修改和分发软件。完整的许可证文本可在本插件附带的 LICENSE 文件中找到。

### 数据收集

**我们不收集的内容：**
- 个人身份信息
- 使用分析或跟踪数据
- 设备信息
- 位置数据
- Cookie 或类似跟踪技术
- 发送给插件作者或任何第三方的任何遥测数据

**我们处理的内容：**
- 你发送给 DSH Agent 的文本提示词
- 你随消息上传的文件（文档、表格、图片…），它们会被上传到你机器上的 Agent 工作区
- Agent 本轮生成的文件（Excel、CSV、PDF…），它们会从 Agent 工作区下载并返回到你的 Dify 对话
- 你配置为凭据的网关 API 密钥（Bearer token）

### 数据处理

**本地处理（主路径）：**
- 所有请求都发送到**你自己配置**的网关地址——默认为你本机的 `http://127.0.0.1:41540`，或你自有的局域网地址
- 提示词、附件与生成文件始终停留在你的机器和你的 Dify 实例中，绝不会传给插件作者或我们运营的任何云服务
- DSH Agent 在本地执行任务（其工作区是本地目录）

**上游 AI 服务：**
- DSH Agent 本身会调用它所登录的 DeepSeek 模型服务；这部分流量由 DeepSeek Harness 依据 **DeepSeek 自身的隐私政策**处理，与本插件无关
- 如果你把网关地址配置为远程主机，数据会流向该主机（由你控制）——请自行评估其安全性

**本地会话状态：**
- 粘性会话映射（Dify 会话/用户 → 网关会话 id）仅保存在插件进程内存中，重启即失效
- 除插件运行时日志外，不做任何永久性数据存储

### 安全措施

- 网关使用 Bearer API 密钥鉴权，密钥安全存储在 Dify 的插件凭据存储中
- DSH 与 Dify 同机部署时，流量不出本机；跨机部署时请将网关保持在可信网络内
- 除你配置的网关地址外，插件不发起任何其他网络连接
